Gross Production Value Dashboard — ParanáCase Study

DataGeo Paraná dashboard of Paraná's Gross Production Value (VBP) by municipality, productive chain and year, built on SEAB/DERAL open data (2012-2024).

Business Intelligence
2024
Paraná, Brazil
View live site avnergomes.github.io/vbp-parana

Project Overview

VBP (Valor Bruto da Produção) is Paraná's official measure of the gross value of agricultural production, published yearly by SEAB/DERAL for all 399 municipalities. The yearly releases are hard to compare across time; this dashboard makes the 2012-2024 series queryable in seconds.

It is one of the ten dashboards of DataGeo Paraná, a personal public project. A Python ETL reads each yearly release, normalises product and municipality names, and consolidates the series into JSON files consumed by a React front-end with rankings, maps and time series by municipality, productive chain and region.

Development Stages

  • Python ETL over the yearly SEAB/DERAL releases (2012-2024)
  • Name normalisation and consolidation by product, municipality and region
  • React dashboard with D3.js / Recharts rankings, maps and time series

Tech Stack

React Vite D3.js Recharts Python GitHub Actions

Outcome

Free public access to 13 years of Paraná's agricultural production value, as part of the DataGeo Paraná ecosystem.
